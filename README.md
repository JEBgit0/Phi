# φ

A personal website by me! With interactive models from my courses at BI Norwegian Business School.
The pages are built with React and TypeScript, and the heavier maths runs in C++ compiled to WebAssembly, directly in the browser.

Live at **https://jebgit0.github.io/Phi/**

## Run it locally

```
npm ci
npm run dev
```

`npm run build:wasm` recompiles the C++ in `cpp/` and needs Docker.
